API de Gestión de Drones

Aplicación académica de escritorio construida con Java 17, JavaFX, FXML, Maven y PostgreSQL. Permite crear, consultar, actualizar y eliminar drones agrícolas o de vigilancia.

Arquitectura

  • modelo: entidades y jerarquía de drones.
  • servicios: Builder, Prototype, Factory y Singleton.
  • dao: contrato CRUD genérico y persistencia JDBC.
  • controlador: interacción entre la vista y la lógica.
  • excepciones: errores controlados mostrados en JavaFX.
